Retail Business Performance & Profitability Analysis

1. Project Objective

The objective of this project is to analyze retail sales data and calculate profit for different product categories.

2. Tools Used

- Python
- Pandas
- Matplotlib

3. Project Description

This project analyzes retail sales and cost data. It calculates profit by subtracting cost from sales and displays category-wise profit. A bar chart is created to visualize the profit of each category.

4. Steps Involved

1. Create a retail sales dataset.
2. Convert the data into a Pandas DataFrame.
3. Calculate profit using Sales - Cost.
4. Display category-wise total profit.
5. Create a bar chart using Matplotlib.

5. Output

- Retail sales data
- Category-wise profit
- Profit bar chart
- Project completion message

6. Conclusion

This project helps understand retail business profitability using Python. It demonstrates basic data analysis and visualization techniques using Pandas and Matplotlib.
